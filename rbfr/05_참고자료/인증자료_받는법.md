# 비건 · NMPA · 유기농 자료를 어디서 어떻게 받나

작성 2026-09-03 / 임단

---

## 먼저 알아 둘 것

이 셋은 **성분 자체의 성질이 아닙니다.** 누군가 발급한 증명입니다.
그래서 어떤 공개 API 에도 없습니다. 식약처 원료성분정보에도 없습니다.

받는 곳과 방법이 셋 다 다릅니다.

| | 어디서 | 자동으로 받을 수 있나 | 유효기간 |
|---|---|---|---|
| **NMPA** | 중국 기사용화장품원료목록 (IECIC) | **된다** — 목록을 받아 대조 | 없음. 목록이 갱신될 때만 |
| **비건** | 원료사 확인서 · 인증기관 | 안 된다 | 인증서에 따라 1~3년 |
| **유기농** | 원료사 인증서 (COSMOS·ECOCERT 등) | 안 된다 | 보통 1년 |

---

## 1. NMPA — 목록을 받아 한 번에 대조

셋 중 유일하게 자동화가 됩니다.

중국 NMPA 가 **기사용화장품원료목록(IECIC)** 을 공개합니다.
이 목록에 있으면 중국에서 쓸 수 있고, 없으면 신원료 등록 절차를 밟아야 합니다.

### 하는 방법

1. NMPA 에서 목록 파일을 내려받는다 (엑셀·PDF)
2. INCI 명으로 우리 성분과 대조한다
3. 있으면 `is_eligible = 1`, 없으면 `0` 으로 넣는다
4. 목록이 갱신되면 다시 대조한다

INCI 명이 완전히 같지 않은 경우가 있어(표기 흔들림) 대조 결과를 사람이 한 번 훑어야 합니다.
**식약처 사전의 영문 표시명칭**을 기준으로 맞추면 잘 붙습니다.

목록 파일만 주시면 대조하는 도구를 만들어 넣겠습니다.
`db/nmpa_sync.php` 같은 걸로 두면 목록이 바뀔 때마다 다시 돌리면 됩니다.

### 주의

목록에 있어도 **사용 부위·농도 제한**이 붙는 경우가 있습니다.
그래서 NMPA 는 인증이 아니라 **국가별 규제**로 다루는 편이 정확합니다.
지금 구조에서는 둘 다 넣을 수 있습니다.

---

## 2. 비건 — 원료사 확인서

비건 인증은 보통 **완제품**에 붙습니다. 원료 단위로는 인증서가 없는 경우가 많습니다.
그래서 실무에서는 원료사에서 **동물유래 여부 확인서**를 받습니다.

받을 것은 이 셋입니다.

- 동물유래 원료를 쓰지 않았다는 확인 (Non-Animal Origin Statement)
- 동물실험을 하지 않았다는 확인 (필요하면)
- 발급처와 문서 번호

완제품 인증을 받으려면 인증기관(비건표준인증원 · EVE VEGAN · The Vegan Society 등)에
원료 확인서를 모아 제출하게 됩니다. 그때 이 자료가 그대로 쓰입니다.

---

## 3. 유기농 — 원료사 인증서

COSMOS · ECOCERT · USDA 같은 기관이 **원료 단위로** 인증합니다.
원료사가 인증서를 갖고 있으므로 받아서 보관하면 됩니다.

받을 것은 넷입니다.

- 인증기관 이름
- 인증서 번호
- **유효기간** — 대개 1년입니다. 지나면 다시 받아야 합니다
- 인증서 사본

유기농 인증은 만료가 잦아서 유효기간 관리가 가장 중요합니다.

---

## 시스템은 이렇게 받아 둡니다

`ingredient_certs` 표에 항목을 넣었습니다.

| 항목 | 무엇 |
|---|---|
| `is_eligible` | 해당 여부 |
| `issuer` | 발급처 (인증기관 또는 원료사) |
| `cert_no` | 인증서·확인서 번호 |
| `doc_url` | 보관한 문서 위치 |
| `valid_until` | 유효기간 |
| `checked_at` | 확인 일자 |

**발급처와 번호가 없으면 검증 화면이 알립니다.** 유효기간이 지난 것도 알립니다.

> 인증 증빙 — 증빙이 없는 것이 12건 있습니다. 인증서 없이 넣은 값은 근거가 되지 못합니다.

지금 들어 있는 인증값은 **현행 데모의 시연용 자료**라 전부 이 경고에 걸립니다.
원료사 자료로 바꾸면 사라집니다.

---

## 원료사에 보낼 요청 — 이대로 쓰시면 됩니다

원료 하나에 표 한 줄씩 채워 달라고 하면 됩니다.

| 항목 | 예시 |
|---|---|
| 원료명 (INCI) | Glycerin |
| 원료명 (한글) | 글리세린 |
| CAS 번호 | 56-81-5 |
| 동물유래 여부 | 없음 / 있음 (있으면 무엇인지) |
| 비건 확인서 번호 | |
| 유기농 인증기관 | COSMOS / ECOCERT / 해당 없음 |
| 유기농 인증서 번호 | |
| 유기농 유효기간 | 2027-03-31 |
| 중국 IECIC 등재 | 등재 / 미등재 / 확인 불가 |
| 권장 배합 농도 | 3.0 ~ 10.0 % |
| 적정 pH | 4.0 ~ 8.0 |
| 용해성 | 수용성 / 유용성 / 양쪽 |
| 함께 쓰기 어려운 원료 | |

**연구소가 실제로 쓰는 원료만** 받으면 됩니다. 2만 종이 아니라 수백 종입니다.

이 양식을 엑셀로 만들어 드릴 수 있습니다. 받아 온 파일을 그대로 넣는 도구도 같이 만들면
원료사에서 채워 준 파일을 올리기만 하면 됩니다. 필요하시면 말씀해 주세요.

## 정리

| | 지금 | 해야 할 일 |
|---|---|---|
| NMPA | 데모값 | IECIC 목록 받아 일괄 대조 — **자동화 가능** |
| 비건 | 데모값 | 원료사 확인서 요청 |
| 유기농 | 데모값 | 원료사 인증서 요청 + 유효기간 관리 |
| 저자극 | 데모값 | 판정 기준부터 정해야 함 (EWG 등급 기준인지) |

가장 빨리 되는 것은 **NMPA** 입니다. 목록 파일만 있으면 됩니다.
