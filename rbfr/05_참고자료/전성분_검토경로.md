## 미국 규제 — 정정 사항

2026-08-19 미팅에서 "미국 규제를 검토했다" 고 한 것은 **캐나다 규제 검토**의 착오였습니다.
상품기획팀에서 2026-09-03 정정했습니다.

미국은 **네거티브 규제**입니다. 법으로 금지·제한한 아래 11종을 빼면 쓸 수 있습니다.

| No | 성분 | 판정 | 내용 |
|---|---|---|---|
| 1 | 비티오놀 (Bithionol) | 금지 | |
| 2 | 클로로플루오로카본 분사제 (CFCs) | 금지 | 미국 내 소비용 에어로졸 화장품의 분사제 |
| 3 | 클로로포름 (Chloroform) | 금지 | 제조공정상 불가피한 잔류량 등 일부 예외 |
| 4 | 할로겐화 살리실아닐라이드류 | 금지 | |
| 5 | 헥사클로로펜 (Hexachlorophene) | 한도 0.1% | 대체 방부제가 효과적이지 않을 때만. 점막 제품 불가 |
| 6 | 수은 화합물 (Mercury Compounds) | 한도 65 ppm | 특정 안구용 제품에서 대체 방부제가 없을 때 등 예외 |
| 7 | 메틸렌클로라이드 / 다이클로로메탄 | 금지 | |
| 8 | 소 유래 위험물질 (BSE) | 금지 | 광우병 위험 관련 특정 소 유래 조직. 성분 하나가 아니라 원료 범주 |
| 9 | 자외선차단 성분 | 조건 | 단일 원료 제한이 아니라 사용목적·표시 규제. 개별 확인 필요 |
| 10 | 비닐클로라이드 (Vinyl Chloride) | 금지 | 에어로졸 제품 성분 |
| 11 | 지르코늄 함유 착물 | 금지 | 에어로졸 제품 성분 |

시스템에는 `db/regulations.sql` 로 들어가 있습니다.

```bash
php db/migrate.php reg
```

## 무첨가 대상 성분

규제상으로는 허용되지만, 피부 자극 이슈로 클린 뷰티 흐름에서 기피 대상이 된 성분입니다.
유화 안정성·사용감·방부력이 좋아 한때 많이 쓰였습니다.

| 분류 | 성분 |
|---|---|
| 파라벤류 (방부제) | 메틸파라벤 · 에틸파라벤 · 프로필파라벤 · 부틸파라벤 · 아이소프로필파라벤 · 아이소부틸파라벤 |
| 페녹시에탄올 (방부제) | 페녹시에탄올 |
| PEG · PEG 유도체 (유화·가용화제) | 피이지-100스테아레이트 · 피이지-40하이드로제네이티드캐스터오일 |
| BHT · BHA (산화방지제) | 부틸레이티드하이드록시톨루엔 · 부틸레이티드하이드록시아니솔 |
| 실리콘류 (사용감 개선) | 사이클로테트라실록세인 · 사이클로펜타실록세인 · 사이클로헥사실록세인 |

**실리콘류는 유럽 수출 시 규제 대상**입니다. CosIng 확인이 필요합니다.
지금은 성분 주의사항에만 적어 두었고, EU 규제 줄은 넣지 않았습니다.
확인하지 않은 것을 확인한 것처럼 두지 않으려는 것입니다.

설계 조건에서 무첨가 분류를 고르면 위 성분들이 산출에서 빠집니다.

## 시스템이 이 자료를 다루는 방식

규제는 자주 바뀝니다. 한 번 적어 둔 값은 금방 낡습니다.

1. **확인한 것만 판정에 쓴다** — 규제 줄에 확정·검토대기 상태가 있고, 확정된 것만 산출·검증에 쓰입니다
2. **AI 는 찾아오기만 한다** — AI 가 사이트를 뒤져 바뀐 것 같은 것을 가져오면 검토대기로 올라갑니다.
   사람이 출처를 열어 확인하고 확정해야 판정에 쓰입니다
3. **자료 없음은 사용 가능이 아니다** — 확인하지 못한 나라는 막지 않되 반드시 알립니다
4. **오래되면 알린다** — 확인한 지 6개월(설정으로 바꿀 수 있음)이 지나면 다시 보라고 표시합니다

화면은 **성분 DB 관리 &gt; 국가별 규제** 입니다.
